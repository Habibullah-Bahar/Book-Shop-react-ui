# 📚 Bookshop

A modern and responsive **Bookshop website UI** built with React and Tailwind CSS. This project focuses on creating a clean, responsive, and user-friendly online bookstore interface.

## 🚀 Live Demo

🔗 [Bookshop Live Demo](https://bookstore-tcj.netlify.app/)

## ✨ Features

* 📚 Modern bookstore UI
* 🏠 Responsive home page
* 📖 Trending and popular books section
* ⭐ Book ratings and author information
* 💬 Customer testimonials slider
* 🛒 Order book popup
* 📱 Fully responsive design
* 🌙 Dark mode support
* 🎨 Tailwind CSS styling
* ✨ AOS scroll animations
* 🔄 Swiper carousel
* 📱 Mobile-friendly layout

## 🛠️ Technologies Used

* **React.js**
* **Tailwind CSS**
* **Swiper.js**
* **React Icons**
* **AOS (Animate On Scroll)**
* **Vite**
* **JavaScript (ES6+)**

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project folder:

```bash
cd bookshop
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
